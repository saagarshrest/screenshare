# Changelog

All notable changes to this project are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-05

### Added
- Mac menu‑bar app that creates a virtual extra display
- 60 fps hardware H.264 streaming to the Android app over USB or Wi‑Fi
- Automatic discovery of the computer on the local network and the phone's hotspot
- Browser viewer with a QR code, for phones without the app
- Landscape and portrait display sizes, HiDPI, and quality presets
- Windows host (`ShareScreen.exe`): Desktop Duplication capture, x264 or NVENC/QSV/AMF, bundled FFmpeg (GPL, see THIRD_PARTY_NOTICES.txt)
- Linux host (`ShareScreen.deb`): virtual X11 monitor via xrandr, x264 or VAAPI
- Release builds of `ShareScreen.dmg`, `ShareScreen.exe`, `ShareScreen.deb` and `ShareScreen.apk`
